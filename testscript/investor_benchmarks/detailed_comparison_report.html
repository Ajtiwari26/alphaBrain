What Happened:

1. AGY synthesizes commit_tx(): acquires active_txs.lock(), then index.lock(). Lock order: (active -> index).
2. AGY synthesizes get(): acquires index.lock(), and inside the loop checks active_txs.lock(). Lock order: (index -> active).
3. Under light single-threaded testing, the code passes cleanly.
4. When subjected to 16 concurrent threads in the stress harness, a classic 3-way cyclic lock inversion deadlock occurs at transaction ~420.
5. The process freezes permanently. Test runner times out after 10,000ms requiring SIGKILL. 0 ops/sec throughput.

// AGY Deadlock Bug (Reverse Order): commit_tx: lock(active_txs) -> lock(index) // Thread A get: lock(index) -> lock(active_txs) // Thread B Result: Thread A waits for Index; Thread B waits for Active. DEADLOCK!

1. INV-ETTA-31 Mandate: ETTA enforces a global monotonic lock hierarchy at compile-time: Rank 1: active_txs -> Rank 2: index.
2. In get(), ETTA snapshots active_txs first (Rank 1) and releases it before acquiring index (Rank 2), strictly preventing nested inverse locks.
3. Stress test executed across 16 threads (8 writers, 8 readers).
4. Completed 8,000 transactions in 34.95 milliseconds.
5. Measured throughput: 13,946 ops/sec. Zero deadlocks, zero lock contention freezes.
