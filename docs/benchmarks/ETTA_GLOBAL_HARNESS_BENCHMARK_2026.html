Executive Summary: The Bi-Cameral Reality of Production AI Agents

AI agent benchmarks frequently mislead operators by conflating local framework micro-benchmarks with live cloud cognitive latency. Architectural Breakdown: Why Etta Beats Heavy Frameworks in Live Cloud Latency

In head-to-head empirical testing against Google Antigravity (agy) running Gemini 3.8 Flash High on the same machine, Etta completed a conversational greeting turn in 16.09s versus 20.05s for raw agy (3.96s advantage). On coding tasks, Etta finished in 21.45s versus 22.87s for agy. This speedup is achieved not by cutting LLM reasoning tokens, but by eliminating wrapper overhead: agy loads a 181 MB binary and transfers 79,103 base tokens of system rules, history, and MCP schemas on every turn. Etta streams with an ultra-compact 1,540 base tokens, cutting network payload, context ingestion latency, and eliminating daemon inter-process communication serialization delays.
